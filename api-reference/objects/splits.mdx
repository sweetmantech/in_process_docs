---
title: "Splits"
description: "Share a moment's revenue between several addresses."
---

Pass `splits` next to `token` in a create request. Splits are optional.

| Field | Type | Description |
|---|---|---|
| `address` | string | Recipient address |
| `percentAllocation` | number | Share of revenue, 0 to 100 |

```json
{
  "splits": [
    { "address": "0xRecipient1", "percentAllocation": 60 },
    { "address": "0xRecipient2", "percentAllocation": 40 }
  ]
}
```

## Rules

- At least 2 recipients.
- Percentages add up to exactly 100.
- Each address must be valid.

## What happens

- The API creates a split contract for these recipients, or reuses the one that already exists for the same recipients and percentages.
- The moment's `payoutRecipient` is set to the split contract. Any `payoutRecipient` you send is ignored.
- The split contract has no owner, so its recipients can't be changed.
- Funds collect in the split contract. [Distribute](/api-reference/splits/distribute) sends them to the recipients.

You can also create a split on its own with [Create split](/api-reference/splits/create).
