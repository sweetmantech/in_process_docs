---
title: "SalesConfig"
description: "Set a moment's price, currency and sale window when you create it."
---

Every create request takes a `token.salesConfig`. Use `fixedPrice` to sell for ETH and `erc20Mint` to sell for USDC.

| Field | Type | Description |
|---|---|---|
| `type` | string | `fixedPrice` (ETH) or `erc20Mint` (ERC20) |
| `pricePerToken` | string | Price in the currency's smallest unit: wei for ETH (18 decimals), 6 decimals for USDC. `"0"` is free. |
| `saleStart` | string | Unix time in seconds. `"0"` starts now. |
| `saleEnd` | string | Unix time in seconds. `"18446744073709551615"` never ends. |
| `currency` | string | ERC20 address. Required for `erc20Mint`, omitted for `fixedPrice`. |

## Free

```json
{
  "type": "fixedPrice",
  "pricePerToken": "0",
  "saleStart": "0",
  "saleEnd": "18446744073709551615"
}
```

## 0.001 ETH

```json
{
  "type": "fixedPrice",
  "pricePerToken": "1000000000000000",
  "saleStart": "0",
  "saleEnd": "18446744073709551615"
}
```

## 1 USDC

```json
{
  "type": "erc20Mint",
  "pricePerToken": "1000000",
  "saleStart": "0",
  "saleEnd": "18446744073709551615",
  "currency": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"
}
```

`0x8335...2913` is USDC on Base.

To change the sale after creation, use [Set sale](/api-reference/sale).
