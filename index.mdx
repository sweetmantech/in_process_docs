In•Process is a platform where artists publish work in progress as onchain moments and others collect them. This API creates moments and collections, sells and collects them, and reads timelines and artist data.

## Choose a starting point

| What you want to do | Start here |

| Act for an artist as an agent | [Agents](/agents) |
| Add sign-in to your app | [Sign in with In•Process](/guides/sign-in-with-in-process) |
| Find an endpoint and its request format | [API reference](/api-reference/introduction) |
| Call the contracts directly | [Deployments](/protocol/deployments) |

## Base URL

```bash
https://api.inprocess.world/api
```

## Authentication

Read endpoints like the timeline and collections are public. Endpoints that act for an artist take one of:

| Credential | Header | Get it from |
|---|---|---|
| API key | `x-api-key: art_sk_...` | [API keys](https://inprocess.world/manage/api-keys) in the app |
| Access token (1 hour) | `Authorization: Bearer <token>` | A 6-digit email code ([Agents](/agents)) or "Copy access token" in the app |
